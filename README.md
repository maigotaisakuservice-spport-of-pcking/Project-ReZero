# Project ReZero (ゴールド・リリース)

**数学的完全性と物理的可逆性を備えた、次世代コンピューティング基盤**

Project ReZeroは、ソフトウェアの「信頼性」を数学的に証明し、計算に伴う「発熱（エントロピー）」を物理的に抑制するための、世界初のネイティブ・リバーシブル・コンパイラスタックです。

## 革新の核心

### 1. ネイティブ AOT コンパイル & LRS
本システムは単なるシミュレータではありません。`.rz` ソースコードを、OS上で直接動作する高度なネイティブバイナリへと変換します。すべての破壊的代入の直前に **Linear Reversible Stack (LRS)** への自動退避コードを注入し、物理的な情報の損失を防ぎます。

### 2. ランドアウアの原理に基づく熱抑制
情報の消去が熱を発生させるという物理法則（ランドアウアの原理）に基づき、プログラムの「エントロピー増大」をリアルタイムで予測。LRSスタックを活用することで、論理的な可逆性を維持し、将来的な可逆計算プロセッサにおける「無発熱計算」への道を切り拓きます。

### 3. Z3による形式検証
配列境界外アクセス、ゼロ除算、NULL参照を、コンパイル時にZ3 SMTソルバを用いて数学的に証明します。バグの存在が疑われるコードはバイナリの生成を拒否する、フェイルセーフな設計です。

## システム構成

- `rezero-core/`: ネイティブコンパイラ (Rust & LLVM-based C)
- `rezero-studio/`: VS Code拡張 (LSP & エントロピープロファイラ)
- `rezero-vs-extension/`: Visual Studio (IDE) 拡張機能
- `rezero-standalone/`: スタンドアロン型 IDE (Electron)
- `index.html`: 白を基調としたプロフェッショナル製品ページ

## 使用方法

### ネイティブビルド
```bash
# 検証と実行ファイルの生成
rezero-core build example.rz -o example.exe
```

### タイムトラベルデバッグ
IDE上で `Step Backward` を実行することで、LRSスタックから復元された過去の状態へと、物理的に1ミリの狂いもなく戻ることができます。
