技術仕様書: Project ReZero

1. 概要

ReZeroは、形式検証と可逆計算を統合したネイティブコンパイラスタックです。プログラムの全実行パスを数学的に証明し、かつ実行状態を物理的に巻き戻すことが可能です。

2. ReZero 言語仕様 (.rz)

@Requires(y > 0)
@Ensures(result > x)
fn calculate(x: int, y: int) -> int {
    let result: int = x + y;
    return result;
}

3. 物理的整合性: LRSスタック

破壊的代入が行われる直前に、旧状態を Linear Reversible Stack (LRS) に退避します。これにより、情報の損失を物理的に防ぎ、ランドアウアの原理に基づく計算熱の最小化を目指します。
