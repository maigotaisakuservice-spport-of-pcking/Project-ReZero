プライバシーポリシー

Project ReZero（以下「本プロジェクト」）は、本ソフトウェアを利用する皆様の個人情報の保護に努めます。

1. 情報の収集について

本ソフトウェアは、ユーザーの氏名、メールアドレス、住所、電話番号などの個人情報を収集することはありません。

2. ローカル処理の原則

本ソフトウェアにおけるすべてのソースコード解析、形式検証、およびコンパイル処理は、ユーザーのローカルコンピュータ上でのみ実行されます。ユーザーのデータが本プロジェクトまたは第三者のサーバーへ送信されることはありません。

3. ログおよび統計情報

本ソフトウェアは、利用状況の分析やエラー改善のために匿名の統計情報を収集する場合がありますが、これに個人を特定できる情報は含まれません。

4. 第三者への提供

本プロジェクトは、法令に基づく場合を除き、収集した情報を第三者に提供することはありません。
